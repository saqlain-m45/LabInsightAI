# LabInsight AI - API Directory

This directory contains server-side API handlers and processing endpoints.

### Contents:
- `rules.php`: Deterministic rule calculation engine for laboratory result classification.
- `patterns.php`: Pattern detection engine (e.g. Microcytic Hypochromic anemia pattern matching).
- `explain.php`: Secure backend API wrapper for Google Gemini AI explanation generation (`gemini-3.6-flash`).
